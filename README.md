# 🏠 BalconyPro - Конфигуратор отделки балконов

Профессиональный веб-конфигуратор для расчёта стоимости отделки балконов с 3D визуализацией.

## 🚀 Возможности

- ✅ Интерактивный 3D конфигуратор
- ✅ Выбор материалов для каждого элемента отдельно
- ✅ Палитра цветов для всех поверхностей
- ✅ Размещение мебели и освещения
- ✅ Расчёт стоимости в реальном времени
- ✅ Система скидок
- ✅ Отправка заказов на email и Telegram
- ✅ Сохранение черновиков
- ✅ Адаптивный дизайн
