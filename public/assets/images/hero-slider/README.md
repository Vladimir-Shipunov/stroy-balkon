# Hero slider photos

Put homepage hero photos in this folder.

Put up to 5 photos here. The site shows the first 5 image files sorted by name.

Recommended file names for the correct order:

- `01.jpg`
- `02.jpg`
- `03.jpg`
- `04.jpg`
- `05.jpg`

Recommended format: JPG/JPEG, horizontal photo, about 1920x1080 or 1920x900.

Also supported by the site: `.jpeg`, `.webp`, `.png`, `.svg`.

Each photo is shown for 5 seconds with a small zoom animation.
